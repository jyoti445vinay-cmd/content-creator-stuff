# 🚀 Projectverse Desktop Apps — CameraVerse & RecordVerse

**Two Projectverse apps. One Windows desktop experience.**

CameraVerse and RecordVerse are being ported from standalone HTML apps into Windows desktop applications using Microsoft WebView2.

## 📸 CameraVerse — Screenshot Edition

- Capture screenshots of your screen
- Select a screen, window, or browser tab
- Preview captured screenshots
- Save screenshots as PNG files
- Copy screenshots to clipboard
- Manage screenshots in the gallery
- Custom CameraVerse application icon

## 🎬 RecordVerse — Screen Recording Edition

- Record your screen
- Select a screen, window, or browser tab
- Microphone audio support
- System audio where supported
- Pause and resume recording
- Stop recordings
- Preview recorded videos
- Export recordings as WebM
- Recording history
- Custom RecordVerse application icon

## 🖥️ Desktop Technology

- HTML-based application interfaces
- Microsoft WebView2
- Windows desktop application ports
- Separate custom icons for both apps

## 📦 Package Information

The ZIP package contains the source code required to build the Windows applications.

**Important:** The ZIP is a source package, not a finished EXE installer. The Windows applications still need to be built and tested.
